# J12 USB Lab (v0.7.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the USB stub with a real USB Host lab: capability detection, live attach/detach, device list, per-device detail (VID/PID, class/subclass/protocol, manufacturer/product, permission-gated serial, interfaces/endpoints/descriptors), copy/export summary. Tag `v0.7.0`.

**Architecture:** `feature:usb`. `UsbViewModel` owns `UsbManager` reads + attach/detach `BroadcastReceiver` (system broadcast, `RECEIVER_NOT_EXPORTED`). USB permission flow uses `requestPermission` + a permission-response receiver. Detail screen walks `UsbConfiguration → UsbInterface → UsbEndpoint`. No new deps.

**Tech Stack:** Kotlin, Compose M3, framework `android.hardware.usb` only.

## Global Constraints

- Requires: skeleton + J07 (`InfoRow`/`SectionCard`), `requiredFeatures` on `Tool` already wired in `CapabilityManager`
- Spec: `specs/feature_plans_v2/features/14_USB_LAB_V2.md`
- **Hard boundary (spec):** no flash-controller model, NAND Flash ID, bad blocks, firmware, ChipGenius-style internals — the detail screen states this limitation explicitly
- Honesty: serial number only after USB permission granted — gated row shows "requires USB permission" + Request button; absent manufacturer/product → `Not exposed`; no host feature → `NOT_SUPPORTED` card, never a failure
- POST-V1 stays out: VID/PID name database, protocol inspectors, session log
- Commit per task, push after every commit; `JAVA_HOME` export for builds
