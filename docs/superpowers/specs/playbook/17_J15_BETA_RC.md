# Journey 15 - Beta and Release Candidate

Version examples:
v1.0.0-beta.1 -> v1.0.0-beta.N -> v1.0.0-rc.1

- [ ] Feature freeze
- [ ] Regression pass
- [ ] Upgrade from previous builds
- [ ] Clean install
- [ ] Permission denied/permanently denied
- [ ] Missing hardware
- [ ] Low storage
- [ ] Offline
- [ ] Rotation/process recreation where relevant
- [ ] Accessibility acceptance
- [ ] Privacy/security review
- [ ] Signing/release key process
- [ ] Release notes
- [ ] README/user guide
- [ ] Distribution requirements
- [ ] Beta tester acceptance

RC gate:
- [ ] Only release-blocking fixes allowed after RC unless freeze is explicitly reopened.
