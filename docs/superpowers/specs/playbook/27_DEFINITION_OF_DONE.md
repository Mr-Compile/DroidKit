# Definition of Done

## Feature DoD
A feature is done only when:
- [ ] Requirement implemented
- [ ] UI/state model complete
- [ ] Loading/content/empty/error handled as relevant
- [ ] Permission denial handled
- [ ] Missing hardware handled
- [ ] Unsupported Android handled
- [ ] Risk confirmation handled if needed
- [ ] Accessibility basics handled
- [ ] Targeted tests/validation passed
- [ ] Real-device validation completed when hardware-dependent
- [ ] Documentation/checklist updated
- [ ] No unrelated change included

## Journey DoD
- [ ] All mandatory deliverables
- [ ] Journey gate passed
- [ ] Known limitations recorded
- [ ] Blockers resolved or formally moved
- [ ] Checklist accurate
- [ ] Next journey ready

## Release DoD
- [ ] Acceptance criteria
- [ ] Regression appropriate to release
- [ ] Build/sign/install
- [ ] Version correct
- [ ] CHANGELOG/release notes
- [ ] Tag
- [ ] Artifact verified
