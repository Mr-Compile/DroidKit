# Home Screen

## Purpose
Immediate device orientation and fastest path to useful tools.

## Hierarchy
1. Compact device identity hero
2. Full Diagnostic CTA
3. Capability/attention strip
4. Favorites/Quick Tools
5. Recent activity

## Hero
Logo/brand should not dominate working space. Show model + Android version + compact capability status.

## UX
If no setup issue exists, do not show warnings.
Recent items should be privacy-safe.
AI card appears only when AI is enabled/configured or as a subtle setup suggestion, not a permanent ad-like block.
