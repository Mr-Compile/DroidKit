# UI/UX Definition of Done

A screen is done only when:
- [ ] Matches semantic design tokens.
- [ ] Uses shared components where appropriate.
- [ ] State comes from existing ViewModel/domain contracts.
- [ ] Loading/content/empty/error states are handled as relevant.
- [ ] Permission/setup/unsupported states are handled.
- [ ] TalkBack labels/roles/states are meaningful.
- [ ] Large text does not clip core actions.
- [ ] Light/dark are usable.
- [ ] Compact and at least one wider layout are reviewed.
- [ ] Risk actions have consequence + confirmation.
- [ ] AI content is distinguished from measured data.
- [ ] No raw secret appears.
- [ ] Changed files identified.
- [ ] Targeted tests/manual checks completed.
- [ ] No unrelated business-logic rewrite.
