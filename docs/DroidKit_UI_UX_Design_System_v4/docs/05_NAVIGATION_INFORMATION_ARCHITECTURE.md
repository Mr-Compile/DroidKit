# Navigation & Information Architecture

## Primary destinations
Home | Tools | Diagnose | Settings

Compact phone: bottom navigation.
Expanded width: navigation rail where appropriate.
Large/tablet: consider list-detail/two-pane for inspectors.

## Home
- device identity summary
- capability status
- Full Diagnostic primary CTA
- favorites/quick tools
- recent tools/reports
- actionable setup warning only when relevant

## Tools
Categories:
Device
Diagnostics
Apps
Hardware Labs
Network
Developer
Advanced
AI (when enabled)

Search is prominent and backed by ToolRegistry metadata.

## Diagnose
Full Diagnostic
Quick Tests
Saved Reports
Recent failures/unfinished session where appropriate

## Settings
Appearance
Accessibility
Permissions
DroidKit Intelligence
Advanced Access/Capability Center
Reports & Data
Safety
About/Licenses

## Deep-link principle
A tool should be directly addressable by stable route/tool ID, but route strings are not the domain model.
