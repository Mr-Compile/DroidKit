# Brand & Visual Foundation

## Brand personality
Technical, trustworthy, precise, modern, repair-oriented, developer-friendly.

## Logo
Primary identity: Candidate 4 geometric DroidKit mark.
- Abstract D / toolkit geometry.
- Green-to-teal accent.
- Strong silhouette that remains recognizable at app-icon size.
- Do not add tiny wrench/details that disappear at small sizes.

## Wordmark
`DroidKit`
- Droid: neutral/on-surface
- Kit: brand accent when contrast allows
- Do not depend on split coloring for accessibility or recognition.

## Splash
Use approved splash image as mood/reference:
- near-black background
- centered mark and wordmark
- controlled green/teal illumination
- minimal loading/initialization experience after system splash if initialization genuinely takes time

Production rule:
Use Android's system splash correctly. Do not intentionally delay launch just to display branding. If startup work continues, transition into an in-app initialization state.

## Visual language
- dark-first technical aesthetic, with complete light theme
- geometric surfaces
- restrained gradients
- subtle depth
- crisp data typography
- clear semantic status presentation
- generous spacing around dense technical information

## Avoid
- neon everywhere
- excessive glass blur
- fake 3D controls
- tiny text
- ambiguous icon-only controls
- huge cards for every row
- dashboard clutter
- red/green-only PASS/FAIL meaning
