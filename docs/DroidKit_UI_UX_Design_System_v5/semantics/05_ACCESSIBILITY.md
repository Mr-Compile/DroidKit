# Accessibility & Compose Semantics
Describe meaning, not appearance.

Good:
`Proximity sensor test. Failed.`
`USB Lab. Inspect connected USB devices. Ready. Button.`
`Diagnostic progress. Test 8 of 16. Microphone test.`

Bad: `Red circle`, `Green icon`, unlabeled `Button`.

Rules: meaningful accessible names; roles/states; merge card semantics when card is one control; decorative imagery excluded; avoid duplicate announcements; associate errors with controls; logical focus order; comfortable touch targets; large text may stack rows; status uses icon+label+color; verify contrast for gradients/glass; review keyboard/focus on larger devices.
