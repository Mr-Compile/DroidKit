# Phone Doctor & Reports
## Phone Doctor
Focused high-contrast UI. Start -> guided test -> progress/instruction -> user result/actions -> summary.
Summary separately counts Passed, Failed, Skipped, Unsupported and Permission Required.
Manual tests require user judgment.

## Reports
Professional/minimal. History -> deterministic detail -> notes/limitations -> export.
AI summary optional and visibly separate.
Delete requires confirmation. Export previews sensitive categories where relevant.
