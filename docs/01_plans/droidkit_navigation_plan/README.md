# DroidKit Navigation Hardening AI Pack

This pack connects navigation hardening to the existing DroidKit architecture rather than replacing it.

Recommended use:
1. Keep the existing DroidKit V1 Completion AI Pack as the overall roadmap.
2. Add this pack as the navigation sub-plan.
3. Give the coding AI `03_AI_FIRST_PROMPT.md` first.
4. Review its NAV-0/NAV-1 evidence before authorizing NAV-2.
5. Then use `00_MASTER_NAVIGATION_PROMPT.md` phase-by-phase.
6. Use `01_NAVIGATION_QA_MATRIX.md` during emulator/real-device verification.

The navigation plan begins at app launch/onboarding, covers the app shell, top-level tabs, ToolRegistry entry routes, nested tools, diagnostics/reports, external settings/provider returns, hardware lifecycle, process restoration, accessibility, tests, and final V1 acceptance.
