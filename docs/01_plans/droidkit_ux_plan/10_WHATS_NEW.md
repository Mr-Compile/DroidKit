# What's New / Changelog

Create a maintainable release-note source rather than scattering strings across UI files.

Suggested data fields:
- Version
- Release date when known
- Change entries

Only include verified release information.

The current release may optionally be highlighted after an app update if the project can reliably detect version transitions and this does not create annoying repeated prompts.

Do not show What's New automatically on every launch.
