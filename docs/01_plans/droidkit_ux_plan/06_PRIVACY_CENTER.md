# Privacy Center

## Destination
Settings → Privacy Center

## Goal
Make DroidKit's data behavior understandable.

Audit the actual application before writing any privacy statement.

Organize information around:
- Data processed locally
- Data sent over the network
- AI requests
- Diagnostic/report data
- Stored preferences/history
- Third-party services actually used

Requirements:
- No unsupported privacy claims.
- Link to official Privacy Policy only if configured.
- Provide relevant controls for optional data-sharing features if they exist.
- Explain how Favorites/Recents or similar local history can be cleared where applicable.
- Do not present generated text as an official legal policy.
