# Tool Information / Learn More

## Goal
Users should understand a utility before granting access or running potentially confusing operations.

For major tools, provide a consistent information surface containing only relevant fields:
- What it does
- How to use it
- Required permissions/access
- Internet requirement
- Device/Android requirements
- Data handling/privacy note
- Limitations
- Troubleshooting/help

Use verified behavior from the actual implementation. Never claim data stays local if code sends it to a server/API.

Provide a consistent info/help entry point from tools where useful. Reuse one component/template instead of creating unrelated layouts for every tool.
