# Accessibility UX Pass

Audit all newly changed surfaces and relevant shared components.

Verify:
- Meaningful screen-reader labels
- Correct roles/states
- Decorative icons excluded where appropriate
- Full-row tap targets
- Adequate minimum touch targets
- Logical focus order
- Large font/text scaling
- No important information conveyed only through color
- Light/dark contrast
- Motion respects existing reduced-motion/platform behavior where supported
- Error/loading/status changes are understandable to assistive technologies

Do not create redundant labels such as "arrow button" when the row already communicates the action.
