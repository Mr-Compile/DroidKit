# Settings Information Architecture

Audit current Settings first. Reorganize only when it improves discoverability without unnecessarily moving established controls.

Target structure when applicable:

GENERAL
- Appearance
- Language
- Default behavior

TOOLS
- Tool preferences
- Favorites
- Permissions & Access

AI & ONLINE SERVICES
- DroidKit AI
- AI Privacy & Data
- Online/service status

DATA & PRIVACY
- Privacy Center
- Local history/data controls
- Export/backup where implemented

ACCESSIBILITY
- Relevant DroidKit accessibility preferences

SUPPORT
- Help & FAQ
- Report a Problem
- Send Feedback

ABOUT
- About DroidKit
- What's New
- Open-Source Licenses

Add Settings search when the number of options justifies it. Search results must navigate directly to the correct setting/destination.
