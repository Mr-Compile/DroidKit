# 02 — UI v6 Design Foundation

Preserve the approved v5 visual identity. UI v6 improves consistency and behavior.

Principles:
- Technical but understandable
- High information density without clutter
- Clear hierarchy
- Consistent interaction patterns
- No unexplained disabled controls
- No color-only meaning
- Honest device/capability states
- Light/dark theme parity
- Accessibility from the component level
- Motion explains state change; it does not delay work

Define canonical patterns for top-level, secondary, detail, list/grid, settings, diagnostic and modal surfaces.
