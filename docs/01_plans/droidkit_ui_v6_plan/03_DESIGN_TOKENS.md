# 03 — Design Tokens

Audit existing tokens before adding any.

Standardize/reuse tokens for:
- spacing scale
- typography roles
- corner radii
- elevations/surfaces
- icon sizes
- component heights
- touch targets
- content widths
- motion durations/easing where appropriate
- semantic colors: normal/info/success/warning/error/disabled

Never hardcode one-off values when an approved token exists. Semantic colors must work in light/dark themes and cannot be the only state indicator.
