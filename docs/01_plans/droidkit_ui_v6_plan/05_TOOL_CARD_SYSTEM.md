# 05 — Tool Card System

Every tool surface should derive from common metadata and consistent card variants.

Card hierarchy:
1. Icon
2. Tool name
3. Short description/category when useful
4. Primary current status
5. Clear affordance/action

Variants: compact list, standard card, favorite/recent, search result.

Avoid multiple noisy chips. Show the most decision-relevant state; detailed states belong on the tool detail/info surface.
