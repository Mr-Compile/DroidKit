# 08 — Search UI

Search should be fast, scannable and local-first.

UI states:
- Initial/suggestions
- Typing/results
- No results
- Loading only when a real asynchronous source requires it
- Error
- Filtered
- Offline: local search continues; only online-dependent results become unavailable

Result rows include icon, title, contextual subtitle/type and only the most useful current status.

Support clear query, keyboard search action, focus behavior, recent searches if already approved, and accessible result semantics.
