# 01 — Existing UI v4/v5 Audit

Before editing, inventory:
- Theme/color/typography/shape/spacing tokens
- Shared Compose components
- App bars and screen scaffolds
- Tool cards/list rows
- Existing chips/badges
- Empty/loading/error components
- NavHost, routes, route arguments and deep links
- Bottom navigation behavior
- Existing vector/SVG/drawable assets
- Tool metadata/registry
- Search implementation and indexes
- Favorites/recents state
- Permission/provider/capability state sources
- Semantics/accessibility

## Deliverable
Create an audit table: Existing / Reuse / Extend / Refactor / Remove duplicate / Risk. Do not code until the audit identifies the smallest migration path.
