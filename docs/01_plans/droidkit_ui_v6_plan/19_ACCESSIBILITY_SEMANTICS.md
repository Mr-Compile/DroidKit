# 19 — Accessibility & Semantics

Audit:
- content descriptions
- merged/duplicate semantics
- headings
- touch targets
- focus order
- state descriptions
- large font scaling
- contrast
- keyboard/D-pad behavior where relevant

Examples:
`NFC Lab, unsupported on this device`
`Battery Information, supported, button`
`Permission required, manage permission`

Do not announce decorative icons separately from their labeled row/card.
