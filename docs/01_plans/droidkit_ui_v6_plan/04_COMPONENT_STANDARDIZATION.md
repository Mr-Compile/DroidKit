# 04 — Component Standardization

Create or consolidate shared components only where reuse is real:
- DroidKitScreenScaffold
- standard top app bar
- section header
- settings row
- tool card/list row
- icon container
- status chip
- info/warning/error banner
- empty state
- loading state
- retry/recovery action
- confirmation dialog
- bottom sheet shell

Migrate incrementally. Do not perform a blind whole-project rewrite.
