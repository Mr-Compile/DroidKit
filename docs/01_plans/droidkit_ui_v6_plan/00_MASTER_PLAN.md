# 00 — UI v6 Master Plan

## Goal
Create **DroidKit UI v6: Unified Interface, Navigation, Routing, Iconography, Search & Status System**.

## Non-goals
- Do not replace working business/domain logic.
- Do not introduce another navigation framework.
- Do not create a second Tool Registry or capability model.
- Do not replace the approved DroidKit logo/brand.
- Do not add fake functionality or decorative status claims.

## Phase order
- [ ] Audit v4/v5 and current repository
- [ ] Consolidate design tokens/components
- [ ] Standardize tool cards
- [ ] Add tool icon/vector registry
- [ ] Improve search and searchable metadata
- [ ] Standardize chips/statuses
- [ ] Standardize loading/empty/error/blocked states
- [ ] Audit/fix routing and back behavior
- [ ] Add state restoration rules
- [ ] Standardize bottom navigation, dialogs and sheets
- [ ] Polish motion/feedback
- [ ] Accessibility/responsive/theme validation
- [ ] Migrate representative screens, then remaining screens
- [ ] Targeted navigation/UI QA
- [ ] Final audit

Use only: PASS / PARTIAL / NOT IMPLEMENTED / BLOCKED / NOT APPLICABLE.
