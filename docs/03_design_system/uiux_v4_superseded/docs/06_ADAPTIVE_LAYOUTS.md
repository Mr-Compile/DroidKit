# Adaptive Layout Plan

## Compact
Single-column, bottom nav, full-width cards, sheets/dialogs for secondary tasks.

## Medium
Wider cards, two-column tool grid where readable, optional navigation rail, inspector sections can use balanced columns.

## Expanded
Navigation rail, list-detail for Apps/USB/Reports, persistent detail pane where useful.

## Rules
- Do not stretch text to huge line lengths.
- Dense technical tables may become key/value grids on wide screens.
- On compact width, technical rows may stack label above value.
- Do not assume portrait.
- Camera/diagnostic full-screen tests may intentionally control orientation only when justified and documented.
