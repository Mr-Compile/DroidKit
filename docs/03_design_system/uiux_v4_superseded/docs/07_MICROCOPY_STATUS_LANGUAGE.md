# Microcopy & Status Language

Use direct technician-friendly language.

Prefer:
`NFC is not available on this device.`
`Microphone permission is required to run this test.`
`USB device detected. Permission is needed before DroidKit can inspect it.`

Avoid:
`Oops! Something went wrong!`
`Device bad`
`Battery health: 82%` unless that value is truly supported and sourced.

## Status vocabulary
Ready
Permission required
Setup required
Unsupported
Offline
Testing
Passed
Failed
Skipped
Unknown
Warning

## AI labels
Always label AI-generated interpretation:
`AI explanation`
`AI recommendation`
Never visually merge AI text with measured results.
