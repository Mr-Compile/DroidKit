# DroidKit UI/UX Design System v5
Supersedes v4 for UI/UX decisions while preserving DroidKit architecture, security, AI, capability and targeted-validation rules.

## Official design language
**Material 3 foundation + Minimalism + Dark Technical UI + Bento composition + Green/Teal Aurora accents + restrained Glass.**

- Material 3: Android behavior/accessibility foundation.
- Minimalism: dense working screens.
- Dark Technical: DroidKit personality.
- Bento: Home/overview only.
- Aurora/Gradient: brand moments.
- Glass: rare elevated/contextual surfaces.

Selected brand direction: **Logo Candidate 9** (futuristic glowing Android head, "Deeper insights. Better devices."). The Compose-drawn ink/glow splash is the startup visual; see `assets/references/logo_candidate9_selected.png`.

## UX promise
Friendly enough for a normal Android user, precise enough for a technician, detailed enough for a developer.

Every unavailable/error state should explain: what happened, why when known, impact, and next action. Sanitized technical details remain available through progressive disclosure.
