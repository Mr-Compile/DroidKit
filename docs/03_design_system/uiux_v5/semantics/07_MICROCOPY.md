# Microcopy
Voice: concise, competent, non-blaming, technically accurate.

Prefer: Permission required, Not supported, Unavailable, Connection lost, Try again, Open settings, Continue without AI.
Avoid: Oops!, Device bad, You failed to..., fake certainty.

If Android cannot expose a value, show `Unavailable` or `Not reported by this device`, never 0/blank/guess.

Destructive buttons use exact verbs: Disable App, Clear Data, Uninstall, Write Tag.
