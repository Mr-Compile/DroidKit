# Inspectors
## Device
Overview/System/Hardware/Memory-Storage/Display/Battery/Capabilities. Dense InfoRows, copy actions, explicit Unavailable. AI Explain is secondary.

## Apps
Compact list->detail; expanded list-detail. Overview/Permissions/Activities/Services/Receivers/Providers/APK/Actions. Elevated actions separated.

## USB
Host status -> device -> identity/classification -> interfaces/endpoints/descriptors. Friendly permission/disconnect states. Never imply inaccessible NAND/controller internals.

## NFC
State -> Scan -> Tag -> Technologies -> NDEF -> Records. Writer uses preview -> confirmation -> result. Tag Doctor uses PASS/WARNING/UNSUPPORTED. No protected credential-cloning promises.
