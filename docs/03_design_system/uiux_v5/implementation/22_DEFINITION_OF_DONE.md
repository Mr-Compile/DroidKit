# UI/UX Definition of Done
A slice is done only when:
- [ ] v5 design language applied appropriately
- [ ] semantic tokens/shared components used
- [ ] state comes from proper ViewModel/domain contracts
- [ ] relevant loading/empty/permission/setup/unsupported/offline/error states handled
- [ ] errors friendly/actionable
- [ ] technical details sanitized/inspectable where useful
- [ ] unsupported/permission/unknown not mislabeled FAIL
- [ ] TalkBack semantics meaningful
- [ ] status not color-only
- [ ] large text works
- [ ] dark/light work
- [ ] adaptive width reviewed
- [ ] destructive actions show target/consequence/confirmation
- [ ] AI content distinct from measured data
- [ ] secrets never displayed/logged
- [ ] changed files identified
- [ ] targeted validation actually run
- [ ] no unrelated architecture rewrite
